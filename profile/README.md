# UCCTB 编辑部

UCCTB 的编辑、翻译与出版协作空间。

## 工作入口

- **翻译项目**：编辑部成员可在 Repositories 中筛选 Topic `kind-translation`；
- **管线与工具**：筛选 Topic `kind-pipeline`；
- **编辑标准**：筛选 Topic `kind-standard`；
- **项目模板**：从私有 `translation-project-template` 创建新译著项目；
- **仓库规范**：编辑部成员参见私有 `editorial-governance`。

## 协作约定

- 每个正式项目有独立仓库和独立历史；
- 所有翻译项目均为私有仓库；
- 跨项目规则与工具不从属于任何译著；
- 凭据和本机配置不得提交；
- 重要修改通过 Pull Request 留下评审记录。
